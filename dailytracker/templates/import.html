Import history

Bring logged days from an Excel workbook, such as an old Daily.xlsx, into your {% if backend == 'sheets' %}Google Sheet{% else %}workbook{% endif %}. You'll see what changes before anything is written.

What the file should look like

  • One tab per month, named like Nov-26, Sept-23 or June-25. Other tabs are skipped.
  • Columns in order: Date, Project, Task, Task Details, AssigneBy, Status. The header names don't matter.
  • Weekend placeholder rows and blank spacer rows are ignored.
  • By default only days that are empty in your sheet are filled. You can choose to overwrite on the next screen.
